# Operation Hydra
## Multi-Vector Cyber Crime Investigation (Simulation)

> Educational project using **fictional and non-routable data only**. No real credentials, malware, victims, or financial accounts are used.

## Objective
Simulate investigation of phishing, spoofing, malware delivery indicators, unauthorized access, and financial fraud.

## Quick Start
```bash
python --version
python scripts/ip_analysis.py
python scripts/transaction_trace.py
```

See `EXECUTION_GUIDE.md` for the complete procedure.

## Project Structure
- `evidence/` - fictional emails, headers and transaction logs
- `analysis/` - investigation findings
- `iocs/` - indicators of compromise
- `scripts/` - safe analysis scripts
- `reports/` - final report
